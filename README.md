# ExcITe Cup 2026 — All Pakistan University Tech Competition

A production-grade, high-impact landing page for the ExcITe Cup 2026 event hosted by Capital University of Science & Technology (CUST), Islamabad. Built with vanilla HTML, CSS, and JavaScript using Vite as the build toolchain.

## Overview

ExcITe Cup 2026 is an all-Pakistan university tech competition featuring 7 competitive events, live countdown, interactive modals (location map, registration form), animated statistics, and a vibrant neon-themed dark UI. The website is fully responsive, optimized for production, and includes advanced CSS animations, 3D transforms, and real-time interactions.

**Event Date:** June 13, 2026  
**Venue:** Capital University of Science & Technology, Islamabad  
**Registration Fee:** Rs. 1,500

---

## Features

### Core Sections
- **Hero**: Animated gradient title, countdown timer (Days/Hours/Minutes/Seconds), badge, CTA buttons
- **About ExcITe Cup**: Event description, embedded video highlight with speaker toggle, location card (clickable map modal), info cards
- **About CUST**: Detailed university information and mission statement
- **Statistics**: 4 animated stat cards (Universities, Events, Cash Prizes, Participants) with counter animations
- **Competition Events**: 7 flip-card events with front/back reveal, organizer info, event descriptions
- **Coordination Committee**: 9 committee members with role badges
- **Important Dates**: Timeline with submission deadline and event day
- **Program Details**: Full-day schedule with 17 activities, times, and venues
- **Downloads**: Brochure, schedule, rules book, and hackathon links

### Interactive Features
- **Fixed Starfield Background**: Multicolor floating glowing dots (Canvas API), scrolls independently from page content
- **Modals**:
  - **Location Map**: Google Maps embed of CUST university, triggered from About section
  - **Registration Form**: Student name, registration number, event selector (themed dropdown), contact, email, with Rs. 1,500 fee note
- **Animations**:
  - Gradient text shift on hero title
  - Floating/bounce keyframes on elements
  - Typewriter reveal on section titles
  - 3D tilt on stat/event/committee cards (on hover/mousemove)
  - Confetti burst effect around trophy
  - Scroll-triggered fade-in for sections
- **Video Control**: Embedded About video with mute/unmute speaker toggle
- **Countdown Timer**: Real-time countdown to June 13, 2026 at 09:00 AM PKT

### Design Language
- **Color Palette**:
  - Primary: Orange (`#ff6b00`)
  - Accent: Pink (`#ff2d78`), Yellow (`#ffe600`)
  - Background: Dark (`#0d0d0d`, `#13081f` gradient)
  - Text: White with muted grays
- **Typography**:
  - Display: Bebas Neue (bold, uppercase, high letter-spacing)
  - Body: Rajdhani (clean, modern, responsive sizing)
- **Effects**: Neon glow, backdrop blur, drop shadows, inset glows, 3D perspective transforms

## Installation & Setup

### Prerequisites
- Node.js v16+ and npm installed
- Git (optional, for cloning)

### Steps

1. **Clone or navigate to project directory**:
   ```bash
   cd my-react-app
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start development server**:
   ```bash
   npm run dev
   ```
   The app will be available at `http://127.0.0.1:5173/` (or next available port if 5173 is in use).

4. **Build for production**:
   ```bash
   npm run build
   ```
   Output is written to `/dist` folder.

## Development

### Key Files

#### `src/main.js`
- **Purpose**: Single entry point generating the entire page DOM via template literals
- **Key Variables**: `countdownTarget`, `stats`, `events`, `committee`, `downloads`, `scheduleTextItems`
- **Key Functions**:
  - `updateCountdown()` — Updates countdown timer every second
  - `animateCounter(el, target, suffix)` — Animates stat numbers on scroll
  - `typewriterReveal(el)` — Typewriter text effect for section titles
  - `openMap()` / `closeMap()` — Location modal controls
  - `openRegister()` / `closeRegister()` — Registration modal controls
  - `iconMark(type)` — Generates inline SVG icons (emblem, file, calendar, sparkle, etc.)
- **Event Handlers**: Scroll fade-in, 3D tilt on cards, keyboard escape for modals, speaker toggle, form submission

#### `src/styles.css`
- **CSS Variables**: `--orange`, `--pink`, `--yellow`, `--bg`, `--text`, `--muted`, `--shadow`, etc.
- **Key Animations**: `gradient-shift`, `float`, `bounce`, `pulse-border`, `shine-sweep`, `trophyPop`, `typewriter`
- **Modal Styling**: `.register-modal`, `.map-modal` with backdrop blur and fixed positioning
- **Form Styling**: Input/select theming with orange border on focus, custom scrollbar for select
- **Responsive**: Mobile-first breakpoints, flexible grid layouts using `min()` and `clamp()`

#### `index.html`
- Minimal markup (all DOM generated by `src/main.js`)
- CDN imports: Google Fonts, AOS, tsParticles
- Single `<div id="app"></div>` container for mounting

### Modifying Content

#### Change Event Date
Update `src/main.js` line ~445:
```javascript
const countdownTarget = new Date('2026-06-13T09:00:00+05:00');
```

#### Update Committee Members
Edit `committee` array in `src/main.js` (lines ~37):
```javascript
const committee = [
  ['Name', 'Role', 'Badge Number'],
  // ...
];
```

#### Add/Edit Events
Edit `events` array in `src/main.js` (lines ~22):
```javascript
const events = [
  { icon: '📌', title: 'Event Name', incharge: 'Organizer', back: 'Description' },

  /* ... */
}
```

## Deployment

### Static Hosting (Recommended)

1. **Build the project**:
   ```bash
   npm run build
   ```

2. **Deploy `/dist` folder to**:
   - **Netlify**: Drag & drop `/dist` folder or connect Git repo
   - **Vercel**: Push to GitHub, import project, auto-deploys on push
   - **GitHub Pages**: Push `/dist` to `gh-pages` branch
   - **Any Static Host**: Upload `/dist` contents to web server (Apache, Nginx, AWS S3, etc.)

### Environment Variables
Currently, no environment variables are required. If adding backend integration (e.g., registration API), add `.env` file:
```
VITE_API_URL=https://your-api.com
VITE_FORM_ENDPOINT=/register
```

Then access via `import.meta.env.VITE_API_URL` in `src/main.js`.

## Performance

### Build Output
- **CSS**: ~5.08 kB gzipped (19.30 kB unminified)
- **JS**: ~9.89 kB gzipped (33.16 kB unminified)
- **Logo**: 49.59 kB
- **Video**: 11.75 MB (streamed, not bundled)

### Optimization Tips
1. **Video**: Ensure `3.mp4` is optimized (use FFmpeg: `ffmpeg -i input.mp4 -vcodec libx264 -crf 28 output.mp4`)
2. **Images**: Use WebP format where supported; compress logo further if needed
3. **CSS**: Currently 700+ lines; consider splitting if project grows
4. **JS**: All logic in single file; tree-shaking not applicable for vanilla JS

## Known Limitations & Future Improvements

### Current Limitations
- **Download Links**: Currently point to external URLs; consider hosting PDFs locally
- **Registration Form**: Logs to console; needs backend API integration for actual submissions
- **Select Dropdown**: Native browser styling varies by OS; consider custom solution (e.g., `<datalist>`) for consistency
- **Map**: Embed loads from Google (requires internet); could use static image as fallback
- **Video**: MP4 format; consider WebM alternative for better compression

### Potential Enhancements
1. Add registration form backend (Node.js + Express, Firebase, etc.)
2. Integrate email notifications on form submit
3. Add event photo gallery section
4. Implement live leaderboard / results page
5. Add testimonials / previous winners section
6. Optimize video format (WebM, HLS streaming)
7. PWA support (manifest.json, service worker)
8. i18n support (Urdu, Punjabi, etc.)
